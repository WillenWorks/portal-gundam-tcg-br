# Legado — planejamento pré-"Nível Arena"

Documentos de planejamento/diagnóstico do redesenho visual do Simulador
("Nível Arena") e da carga inicial de dados do catálogo, escritos ANTES ou
DURANTE o trabalho — não durante o registro final. O que foi de fato
implementado está narrado, sessão a sessão, em `docs/18` até `docs/36`
(numeração cronológica principal do projeto).

Mantidos aqui por valor histórico (o raciocínio/diagnóstico por trás das
decisões), não como referência viva — para o estado atual do simulador,
prefira sempre os docs numerados.

- `PLANO_REDESENHO_VISUAL_SIMULADOR.md`, `PLANO_REFINAMENTO_ARENA_3D.md`,
  `implementation_plan.md`, `ROTEIRO_ORQUESTRACAO_CLAUDE_CODE.md` — plano
  original do pivot visual "Nível Arena" (pré-`docs/30`).
- `PLANO_CORRECAO_ARTE_EFEITOS.md`, `PLANO_CORRECAO_EFEITOS_UX_LIFECYCLE.md`,
  `PLANO_ESPELHAMENTO_HUD_FIMDEJOGO.md` — rodadas intermediárias de correção
  visual/UX (pré-`docs/33`).
- `INSTRUCOES_AGENTES_SIMULADOR.md` — guia operacional de uma rodada
  específica do redesenho visual (referencia um artifact externo).
- `INSTRUCOES_APITCG.md`, `INSTRUCOES_CATALOGO_ADMIN.md`,
  `INSTRUCOES_TAXONOMIAS.md` — carga inicial do catálogo de cartas
  (import da API TCG, filtros do admin, seed de traits/mídias).
